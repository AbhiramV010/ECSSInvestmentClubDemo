# Buy Low, Sell High — ECSS Investment Club
A 30-second stock trading game for the ECSS Investment Club fair booth, styled like Windows 98.
Players enter their 9-digit student number, press BUY once and SELL once, and try to lock in the biggest profit.
Run `run.bat` (needs Python on PATH) to serve the game at http://127.0.0.1:6767 and open it in your browser.
The Top Traders leaderboard is hidden by default: press Ctrl+Shift+F12 to show it, and click its ✕ to reset scores and let everyone play again.
